Évolutions : l'objet requis est donné. Descriptions : le texte du jeu est donné.

Un indice se débloque après essais (compté 💡 dans le partage). Trouver l'arme du jour donne un bonus pour le personnage du jour, et inversement.

Défi du jour : le même pour tous, sans les éléments obscurs. Archives : les 30 derniers jours. Options : mode difficile, essais limités, liste des réponses encore possibles.
